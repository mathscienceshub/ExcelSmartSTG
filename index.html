Product features

A focused timetable workspace

EXCEL Smart STG is designed to help school administrators move from setup to a printable timetable without losing control of teacher loads, split classes and final refinements.

⚡

Timetable generation

Creates class and teacher timetables while checking clashes, breaks, teacher availability and daily subject limits.

🔗

Combination classes

Supports split or combination classes where linked subjects run at the same time across different rooms or class groups.

🧭

Manual refinement

Move or swap timetable blocks while the system checks the teacher, class and affected slot logic.

📊

Reports

Review unplaced blocks, workload concerns, warnings, timetable readiness and printable outputs.

🔐

Licence control

School-specific licence files help control activation, demos, annual use and renewals.

💾

Backup and restore

Protect setup data, assignments and timetable work through JSON backup and restore.
